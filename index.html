Web Vulnerability Foundations & Burp Suite

PortSwigger Web Security Academy
Web Security
⚡ Prerequisites

📋 Tactical Action Checklist
🎯 Exit Criteria / Done When

Burp Suite An interception proxy tool that captures, inspects, and modifies web traffic between a client browser and backend web servers.
SQL Injection (SQLi) Inserting untrusted database queries into application inputs to bypass authentication, exfiltrate data, or alter database contents.
Cross-Site Scripting (XSS) Injecting browser-executable JavaScript that executes within victim browser sessions to hijack cookies or perform unauthorized actions.
Path Traversal Manipulating file directory variables (e.g., using ../) to read restricted files outside the server root directory.

Web & API Security

GraphQL An API query language allowing clients to request exact fields, vulnerable to sensitive data leaks if introspection is left exposed in production.

STEP 09 • PHASE 3 • Months 8–9

Practical Cryptography & Scripting Attacks

picoCTF Crypto + CyberChef
Cryptography
⚡ Prerequisites
Python scripting fundamentals, basic modular arithmetic (modulo operations), and bitwise logic.
📋 Tactical Action Checklist
🎯 Exit Criteria / Done When
Can write a Python script that connects to a socket, parses encrypted parameters, and computes the decrypted flag.
🔍 Technical Definitions & Concepts ▶
Symmetric vs Asymmetric Crypto Symmetric encryption uses a single shared secret key (e.g., AES); asymmetric uses mathematically linked public/private keypairs (e.g., RSA).
XOR Cipher An additive mathematical cipher relying on the reversible bitwise XOR operation (A ^ B ^ B = A), widely used in CTF challenges and malware obfuscation.
CyberChef A web-based graphical Swiss Army knife application for decoding encodings, decompressing payloads, and parsing complex data representations.

TryHackMe PrivEsc Rooms
Systems & PrivEsc
⚡ Prerequisites
Linux command-line fluency (Step 1) and basic Windows operating system administration concepts.
📋 Tactical Action Checklist
🎯 Exit Criteria / Done When
Given standard shell access, can discover and exploit a misconfiguration to obtain root/admin access.
🔍 Technical Definitions & Concepts ▶
Privilege Escalation (PrivEsc) The adversarial technique of exploiting configuration bugs, weak permissions, or kernel flaws to upgrade low-level user access to root or SYSTEM privileges.

GTFOBins A curated reference catalog of legitimate Unix binaries that can be leveraged to bypass local security controls, spawn elevated shells, or read restricted files.
